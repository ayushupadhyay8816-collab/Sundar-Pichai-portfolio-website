SUNDAR PICHAI PORTFOLIO WEBSITE
================================

Files
-----
- index.html : Main responsive portfolio webpage
- style.css  : External CSS3 stylesheet

How to run
----------
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Keep an internet connection available so the gallery photos and Google Fonts can load.

Before submission
-----------------
1. Open index.html in a code editor.
2. At the bottom of index.html, replace:
   - "Enter your name"
   - "Enter your enrollment number"
   with your own student details.
3. The contact form is a front-end demonstration only; it does not send or store messages.
4. The photographs are loaded from Wikimedia Commons. Review the individual image pages for licensing and attribution requirements before publishing.
5. The assignment PDF asks you to host the project with GitHub Pages and submit both the published link and ZIP folder on Google Classroom.

Assignment alignment
--------------------
- HTML5 structure, headings, paragraphs, hyperlinks, images, lists, education table and contact form
- External CSS only
- Element, class, ID and universal selectors
- Colors, fonts, backgrounds, margin, padding, borders and border-radius
- Flexbox and responsive media queries
- About section contains approximately 170 words
- Six major contributions with image banners, education table, achievements, six gallery images and student footer details

Visual update: the contributions section now uses image banners and the gallery contains six image cards.
